# KEY 按键驱动

## 1. 模块职责

`Drivers/User/KEY` 负责 START 按键的电平读取与消抖，并在**按下沿**向上层报告一次事件。

主要接口：

- `Key_Init()`：初始化消抖状态；首次扫描前未初始化时会自动调用。
- `Key_Up_Scan()`：非阻塞扫描；仅在稳定按下沿返回 `true`，其余情况返回 `false`。

## 2. 关键参数边界

- `KEY_DEBOUNCE_MS`（`Key.h`）：原始电平变化后需保持该时长才认定为稳定状态。
- `KEY_LEVEL_PRESSED`（`Key.c`）：按下有效电平，当前与 `gpio.c` 中 START 引脚的下拉配置对应。
- 状态量 `s_initialized`、`s_stable_pressed`、`s_last_raw_pressed`、`s_raw_change_tick` 均为文件内私有状态，维持现有状态机迁移顺序。

## 3. 禁止改动项

- START GPIO 端口/引脚与上下拉配置（属 `Core/**`、`gpio.c` 生成文件）。
- `KEY_DEBOUNCE_MS`、`KEY_LEVEL_PRESSED` 及“只在按下沿上报一次”的事件语义。
- 消抖状态机中的“变化当帧不产生事件”“未稳定继续等待”“更新稳定状态后返回按下沿”三段顺序。
- 不得在扫描路径新增稳态日志或阻塞延时（见 `docs/log-usage-policy.md`）。

## 4. 调试入口

本模块不导出 shell 命令。调试方式：

- 在任务循环中周期调用 `Key_Up_Scan()`，用断点或一次性计数器观察按下沿。
- 用示波器/逻辑分析仪观察 START 引脚电平与消抖窗口。
- 通过上层任务启动/停止行为间接验证按键事件，不额外增加日志调用。

## 5. 验证方式

- 静态验证：`git diff` 确认仅注释新增；`Key.h` 宏值与状态机表达式不变；数字多重集门禁通过。
- 现场验证：短按、长按、快速连续按 START，确认每次只上报一次按下事件，松开不误触发。
- 当前环境无 ARM 整机，电气消抖边界与按键手感需后续实车确认。
